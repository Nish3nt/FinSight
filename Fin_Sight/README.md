# 💹 FinSight — AI-Powered Market Intelligence Dashboard  

> A modern Streamlit application that blends **machine learning, finance, and NLP** to provide deep insights into stock market behavior — from price prediction to sentiment analysis.

---

## 🚀 Overview  

**FinSight** is a full-featured financial analytics dashboard that enables users to:  
- 📈 Visualize live stock data  
- 🧠 Predict trends using **Prophet** and **LSTM** models  
- 📰 Analyze news sentiment using **TextBlob + NewsAPI**  
- 📊 Compare multiple stocks interactively  
- 💡 Derive AI-based insights connecting price action with market tone  

The app showcases practical use of **data science, time series forecasting, and financial analysis** — all in one intuitive interface.

---

## 🛠️ Tech Stack  

| Layer | Technology |
|:------|:------------|
| **Frontend** | Streamlit, Plotly |
| **Backend** | Python, yFinance, Prophet, TensorFlow |
| **APIs** | NewsAPI |
| **Utilities** | Pandas, NumPy, TextBlob |
| **Deployment** | Streamlit Cloud |
